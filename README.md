## 🚀 Deployment Instructions

### GitHub Pages Deployment

1. **Create a GitHub Repository**
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Elitetom Gadgets website"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/elitetom-gadgets.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**
   - Go to repository Settings
   - Navigate to "Pages" section
   - Select "main" branch
   - Click Save
   - Your site will be live at: `https://YOUR-USERNAME.github.io/elitetom-gadgets/`

### Alternative Deployment Options

#### Netlify
1. Drag and drop the folder to Netlify
2. Site will be live instantly
3. Custom domain supported

#### Vercel
1. Import GitHub repository
2. Deploy with one click
3. Automatic updates on push

### Updating Contact Information

In `index.html`, update:
```html
<!-- WhatsApp Number -->
<a href="https://wa.me/2348105772904">

<!-- Phone Number -->
<a href="tel:+2348105772904">

<!-- Instagram -->
<a href="https://instagram.com/elitetom_gadgets">
```

### Changing Colors

In `styles.css`, modify the CSS variables:
```css
:root {
    --deep-blue: #0A1F44;      /* Primary color */
    --bright-orange: #FF6B35;   /* Accent color */
    --clean-white: #FFFFFF;     /* Background */
}
```

### Updating Business Hours

In `index.html`, find the business hours section:
```html
<div class="business-hours">
    <!-- Update times here -->
</div>
```
